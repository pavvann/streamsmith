## Direction
A treasurer's instrument panel: calm, spacious, one dominant reading per section, the receipt as a stamp of trust. Light theme only, committed. Editorial restraint over dashboard density: fewer boxes, more air, real hierarchy. Nothing here is a card grid of equal tiles.

## Palette (CSS variables; use exactly these hexes, derive tints with color-mix)
- `--ground: #edffec` (Honeydew) page background.
- `--ink: #48435c` (Vintage Grape) primary text and rules.
- `--muted: #5a5766` (Charcoal) secondary text.
- `--go: #61e786` (Light Green) the single "verified / allowed / rotate" accent. Used sparingly: the pipeline-verified stamp, the decision when it is `rotate`, allow outcomes, sparkline endpoints.
- `--accent: #9792e3` (Soft Periwinkle) the structural accent: section eyebrows, the observed-window band, links, focus rings, the guardrail meter fill.
- Surfaces: `--paper: #ffffff` for the few raised panels; `--paper-2: color-mix(in srgb, #edffec 60%, #ffffff)` for inset bands.
- Semantic (separate from accents): hold/warn `#b6890f` on `#fff6d6`; denied/refused `#a13d3d` on `#fde2e2`. Never use purple for errors.
- Hairlines: `color-mix(in srgb, var(--ink) 14%, transparent)`.

## Type (Google Fonts via next/font/google; real fallback stacks)
- Display and numerals: **Fraunces** (variable, opsz), weights 500/600, `font-variation-settings: "SOFT" 30`. The big readings (growth bps, lag, held amounts) are Fraunces at 44–64 px with `font-variant-numeric: tabular-nums`. Headline "Vaultpilot" and section titles in Fraunces 600.
- Body and labels: **Source Serif 4** for prose (rule text, disclosures, notes) at 15–16 px / 1.55; **Source Sans 3** for UI labels, table cells and eyebrows (11.5 px uppercase eyebrows with 0.08em tracking).
- Mono for hashes/ids/commands only: **JetBrains Mono** 12.5 px, colored `--muted`. Truncate hashes to `0x1234…abcd` with a copy button; the full value in `title=`.
- Do not use Inter, Roboto, Arial, system-ui, Space Grotesk, IBM Plex, or Bricolage.

## Layout (max-width 1160 px, 32 px gutters, 12-col grid, gaps 28–40 px; sections separated by generous vertical space, not by boxes)
1. **Masthead** (no panel): left: "Vaultpilot" Fraunces 34 px + a one-line Source Serif subtitle "Idle USDC, moved only inside the treasurer's policy." Right: a status strip with three small stamps in a row: mode (`DRY RUN` amber / `EXECUTE` green), data source (`ClickHouse Cloud · read-only`), Privy (`live`). Below the strip, muted 12.5 px: "decided {decidedAt} · read {readAt}". A quiet "Refresh" text button.
2. **Decision** (the hero, spans 8 cols; right 4 cols = Position): a full-width band with a 4 px left rule in `--go` (rotate) or amber (hold). Inside: eyebrow "DECISION", then the verdict word in Fraunces 64 px lowercase ("hold" / "rotate"), then the reason sentence in Source Serif 17 px max 62ch. Under it a compact "rule" strip: five rule facts as label/value pairs in one row (min differential, min window, cooldown, guardrail, lag limit), Source Sans. Refusals (when any) as a bulleted list with the `code` in mono and the message in serif, no red boxes: a small amber dot per item.
3. **Position** (4 cols): two rows, one per vault: Fraunces 40 px amount + symbol, vault label in Source Sans 14 px, a tiny `source`/`destination` stamp when the decision names it, and the wrapper fee as one muted line "10% of generated returns goes to the app (fee wrapper)". Addresses collapsed under a "details" disclosure (`<details>`), mono.
4. **Observed window** (full width, the graphical centerpiece): a horizontal band in `--paper-2` with a periwinkle hairline top and bottom. Left column (3 cols): eyebrow "OBSERVED WINDOW", then Fraunces 44 px "{hours} h", then "{first} → {last}" blocks in mono, then "{n} observations" and the two ISO timestamps muted. Right (9 cols): two rows, one per vault, each an **inline SVG sparkline** of share value over the window using the data available: if only first/last exist, draw a two-point line with a filled endpoint and a dashed baseline; the vault label, first → last share value in mono, and the growth reading in Fraunces 32 px `{bps} bps` with `--go` when positive. Below the sparklines a single row: "differential {x} bps · minimum to act {min} bps" in Source Sans, and if not computable say so in words.
5. **Guardrail** (full width, thin): eyebrow "24 H NET THIRD-PARTY OUTFLOW · our own flows excluded". One horizontal meter per vault: a 6 px track (hairline) with a periwinkle fill proportional to `outflowBps / limitBps`, a tick at the limit, the number `{bps} bps` in Fraunces 22 px right-aligned, the normalized amount muted mono. Over-limit turns the fill to the denied red.
6. **Three quiet columns** (4/4/4): **Policy** (methods as two small stamps, vault ids mono, per-action cap in Fraunces 28 px, "everything else: denied by default" as a line, daily cap as a thin meter spent/total, the daily-cap disclosure in serif 14 px); **Pipeline** (the stamp: a circular 64 px badge with a check in `--go` reading "verified" or a slashed circle in red reading "refused: {reason}"; under it package name+version, `outputModuleHash` and `packageHash` truncated mono with copy, deploymentMode, "head {h} · chain {c} · lag {lag} of {limit}" with the lag in Fraunces 28 px); **Control** (wallet address mono with copy, treasurer key, agent signer, policy id; the `control` sentence in serif; the revocation command in a mono block with a copy button and a one-line caption "signed by the treasurer key; the agent cannot run this").
7. **Ledger** (full width, two columns 7/5): **Policy outcomes** as a timeline list (dot per entry: green succeeded, red denied/rejected, amber else; when, kind · vault, amount right-aligned Fraunces 18 px, status stamp, note in serif muted) and **Transactions** (Basescan links, mono, truncated; empty state in serif: "No transaction yet. The business wallet is funded by a human; the agent only moves what is already in the two approved vaults."). Footer line muted: read time, origin, ledger path, any `errors` as amber notes.

## Motion
One page-load sequence only: sections fade+rise 8 px with staggered `animation-delay` (0, 60, 120… ms), 380 ms ease-out, from a visible resting state (no opacity:0 without the animation). Sparkline draws in via stroke-dashoffset once. Copy buttons flash "copied" 900 ms. Refresh: the timestamp cross-fades. Respect `prefers-reduced-motion`.

## Details that matter
- Every number that is a reading is Fraunces + tabular-nums; every label is Source Sans; every hash is mono and truncated with copy. Never mix.
- Keep all facts from the current Dashboard.tsx; you may reorder and re-group, not drop.
- Empty and null states are sentences, not dashes, where the meaning matters ("differential not computable: one window is under the minimum").
- Accessibility: visible focus rings in periwinkle, buttons are buttons, tables (if any remain) have headers, color never the only signal (stamps carry words).
- No emoji, no gradients on white, no drop shadows heavier than `0 1px 0 rgba(72,67,92,.06)`, no rounded-lg-on-everything: radius 6 px on stamps/buttons, 10 px on the two raised panels max.
- Fonts via `next/font/google` with `display: 'swap'` and declared fallbacks (`Georgia, serif` for Fraunces/Source Serif; `"Helvetica Neue", Arial, sans-serif` for Source Sans; `ui-monospace, Menlo, monospace` for JetBrains Mono). Disk is limited: no new npm dependencies.
