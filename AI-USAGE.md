# AI usage disclosure

This project was built with heavy use of AI coding tools, as permitted by ETHOnline 2026 rules, and this
file records where and how.

Claude Code and its sub-agents wrote the code, working from human-written specifications, quality gates and
briefs. The human made every decision: scope, architecture, the public contract, what counted as passing,
what shipped. Each brief is committed under `specs/briefs/`, so the instruction behind every workstream is
readable alongside the result.

- **Second opinion:** OpenAI Codex CLI reviewed the project draft and took part in a three-round design
  discussion (`docs/research/codex-discussion.md`).
- **Substreams code:** generated by Claude Code using the official StreamingFast Substreams skills inside the
  recorded one-prompt run (`runs/`). A hand-built reference implementation was written first, to design the
  public schema, the tests and the gate assertions; it is disclosed here and kept under
  `packages/erc4626-flows/`.
- **Prompts and planning artifacts:** `specs/` (public contract, gate, plugin config, the verbatim one-prompt
  instruction), `docs/PROJECT.md` (plan), `docs/TASKS.md` (tracker).

Every file in this repository was reviewed by a human before submission.
