# AI usage disclosure

This project is built with heavy use of AI coding tools, as permitted by ETHOnline 2026 rules, and this file records where and how.

- **Orchestration:** Claude Code (Claude Fable 5.1) acts as project manager: decides scope, writes task lists, dispatches sub-agents, reviews outputs. Human (Pawan) approves scope, runs account logins, funds wallets, records the demo, reviews every commit.
- **Sub-agents:** Claude Code sub-agents implement individual workstreams from written briefs. Each brief is committed under `specs/briefs/`.
- **Second opinion:** OpenAI Codex CLI reviewed the project draft and participated in a three-round design discussion (`docs/research/codex-discussion.md`).
- **Substreams code:** generated by Claude Code using the official StreamingFast Substreams skills inside the recorded one-prompt run (`runs/`). A hand-built reference implementation was written first to design the public schema, tests and gate assertions; it is disclosed here and kept under `packages/erc4626-flows-reference/` if retained.
- **Prompts and planning artifacts:** `specs/` (public contract, gate, plugin config, the verbatim one-prompt instruction), `docs/PROJECT.md` (plan), `docs/TASKS.md` (tracker).

Every file in this repository was reviewed by a human before submission.
